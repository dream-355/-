# 能力边界与使用说明

## 这个系统能做什么

- 依据 Neo4j 医疗知识图谱检索相关实体与关系，给出可追溯的知识线索。
- 识别红旗症状并优先提示 120 或急诊。
- 记录连续体征，识别趋势偏离与异常区间。
- 结合档案（过敏史、基础疾病、用药）做个性化提示。
- 整理就诊前摘要，便于与医生沟通。
- 对每条回答做规则 + 大模型二次复核，标注是否修正过。
- 根据一般膳食原则和症状场景提供饮食与低强度活动参考。

## 这个系统明确不做

- 不做诊断，不出具检查结论，不替代医生。
- 不给处方、不调整既有用药、不给具体药物剂量。
- 不承诺药品价格实时准确，页面价格为带日期的参考区间。
- 不提供医生审核结论。界面上标注的是“AI 医学复核”，不代表任何医疗机构或执业医师的审核。
- 不处理急症。识别到急症信号时只做转运提示，不做进一步处置建议。
- 不提供个体化营养处方、康复处方或疾病治疗餐。肾病、心衰、孕期等情况必须由医生或注册营养师进一步评估。

## 遇到红旗症状怎么办

胸痛伴呼吸困难、意识障碍、口角歪斜或单侧肢体无力、大出血、抽搐、严重过敏、自杀风险、孕产急症，请立即拨打 120 或前往最近急诊，不要等待系统回答，也不要自行驾车。

## 数据与隐私

个人健康数据与对话保存在本地数据库中，不写入医疗知识图谱；上传图片不落库。演示账号数据可用 `python scripts/reset_demo.py` 重置。

## 评分口径提醒

没有执业医师参与审核时，任何“医生审核/临床验证”的表述都属于不实宣传。本项目统一表述为“AI 医学复核（规则引擎 + 大模型）”，如后续引入医生审核，应单独增加字段并注明医师资质信息。
