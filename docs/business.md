# 价值、成本与可持续性

## 目标用户

1. 慢病自我管理人群（高血压、糖尿病、血脂异常）：需要连续记录与趋势解释，但不需要每次就医。
2. 就诊前需要整理病史的人：把散落的症状、指标、用药整理成一页摘要给医生看。
3. 医学科普与健康教育场景：学校、社区卫生服务站的辅助问答。

## 使用场景与价值

- 症状出现时先判断风险等级，红旗症状立即指引急诊，避免延误。
- 把“连续记录”变成可解释的趋势结论，而不是一堆数字。
- 就诊前摘要减少沟通成本，提高门诊效率。
- 所有回答带证据编号与复核状态，降低“AI 胡说”的信任成本。

## 成本结构（估算口径）

- 知识图谱：Neo4j Community，自托管，无授权费。
- 推理成本：按大模型 token 计费。以单次问答约 2,000 输入 + 800 输出 token 估算，成本随所选模型档位线性变化；本地规则降级路径不产生模型费用。
- 服务器：2 核 4G 可支撑演示与小组使用；并发上升需要先扩 Neo4j 内存再扩 CPU。
- 维护成本主要在图谱质量与评测集扩充，而非模型调用。

以上为结构性估算，具体金额取决于所选模型定价与服务器规格，需在答辩材料中按当期价格重新核算，不要直接引用旧数字。

## 可持续性

- 检索层与生成层解耦：模型可替换，知识图谱与评测集可沉淀。
- 所有评测脚本可离线复现，便于持续回归。
- 若接入院内系统，需补齐 RBAC、审计日志、字段级加密与临床验证流程，这属于独立的合规工程，而不是当前版本的能力。

## 风险与偏差

- 知识图谱覆盖不均：部分疾病缺少治疗或检查关系边，导致证据可得率约 83%，系统会降级为澄清追问而不是编造。
- 药品价格是带日期的参考区间，不可当作实时报价。
- 无执业医师审核，不能宣称临床验证。
- 真实用户测试尚未完成，用户满意度与任务完成率数据缺失，这是当前评分的主要不确定项。
