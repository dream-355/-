# 传智杯答辩与演示方案

## 一句话定位

知衡健康不是“套壳聊天机器人”，而是一个把 14 万级 Neo4j 医疗知识图谱、个人连续健康档案、急症规则与大模型受约束生成连成闭环的可信健康智能体。

## 核心亮点

1. **真图谱，不是伪知识库**：直接复用 141,178 个真实医疗实体和 684,564 条关系。
2. **回答可解释**：每轮对话右侧展示命中实体、证据数量和真实关系链。
3. **混合召回**：80,955 个本地医疗实体向量索引与 Neo4j 全文检索互补，按关系意图过滤噪声。
4. **逐条可溯源**：回答中的 `[E#]` 可展开主体、关系和客体，不再只写模糊的“图谱中”。
5. **多模态与人体定位**：DeepSeek Vision 分析健康图片；用户可点击男女全身三维粒子人体模型定位不适部位，并自动生成更完整的咨询描述。
6. **模型受约束**：严格提示词禁止编造剂量、诊断与检查结论；模型故障后自动降级。
7. **独立安全层**：大模型之外还有急症规则引擎，胸痛伴呼吸困难等场景优先提示 120。
8. **连续健康记忆**：保存会话摘要、健康档案、过敏史和 7 天指标趋势，能理解上下文。
9. **3D 医学图谱**：无 Three.js、无 CDN、无 Node，Canvas 自研三维渲染，现场断网可运行。
10. **隐私边界清晰**：图片不落库，健康数据不写入医疗知识图谱，模型 Key 仅在后端环境变量中。

## 五幕演示脚本

### 第 1 幕：10 秒建立可信感

打开 `http://127.0.0.1:8000/`，在登录页点击“游客快速体验”。

说明：左侧显示 141K 实体、685K 关系是真实 Neo4j 统计；总览页已经根据演示用户 7 天数据生成健康评分、趋势与 AI 洞察。

### 第 2 幕：知识图谱不是背景图

进入“医疗知识图谱”，拖拽三维网络，搜索“高血压”或点击实体。

说明：点击后会实时向 Neo4j 查询一跳关系，节点与边不是写死动画。

### 第 3 幕：带证据的医疗问答

进入“健康咨询”，输入：

> 我最近起床时偶尔头晕，平时血压偏低，最近睡眠不足，可能和什么有关？

重点展示：

- AI 结合健康档案与本次问题；
- 右侧出现“头晕”等实体；
- 展示症状、科室等相关关系；
- 明确回答“相关性不是诊断”；
- 对话自动保存，刷新后仍存在。

### 第 4 幕：急症安全边界

打开“智能检测”，输入：

> 突然胸痛，呼吸困难，还一直出汗

重点展示：

- 风险等级立即变为急症；
- 红色“胸痛伴呼吸困难”规则证据；
- 首屏明确提示拨打 120；
- 不给出未经证据支持的药物或剂量。

### 第 5 幕：长期健康管理

进入“健康档案”，添加一条心率或睡眠记录。

说明：新增数据后，评分、趋势、AI 洞察立即刷新，体现“对话智能”向“连续健康管理”的延伸。

## 评委常见问题

### 与直接使用 DeepSeek 有什么区别？

DeepSeek 负责自然语言组织，但不能单独保证医疗事实。我们使用 Neo4j 先限定证据范围，再要求模型只能依据证据回答；模型失败时仍有本地规则答案。系统还展示证据链，用户能够看到“为什么这样回答”。

### 图谱关系是否会导致错误疾病推荐？

会避免把单条关系直接表达为诊断。提示词明确要求使用“可能相关”“需结合”等措辞，回答页面也标注知识相关性与风险等级，并声明不能替代医生。

### 如何保护用户隐私？

用户档案和会话保存在本地 SQLite，不写进知识图谱；模型 Key 只在服务端读取。登录后按用户 ID 隔离数据。当前比赛版本可进一步加入字段级加密、操作审计和数据删除确认。

### 断网怎么办？

前端不使用 CDN，所有界面资源均在项目内。Neo4j 和 Python 服务在本机运行。无 DeepSeek Key 时，系统会自动使用本地图谱证据规则引擎，因此现场不会白屏。

### 如何识别急症？

系统采用独立于大模型的规则层，识别胸痛伴呼吸困难、卒中样表现、意识障碍、活动性出血、抽搐、严重过敏、自伤风险和孕产急症，并将结果强制放在回答前部。

### 如何扩展到真实医院？

可接入院内指南、药品说明书与脱敏病历；增加医生审核、RBAC、审计日志、字段级加密、模型输出评测和临床安全验证。当前版本定位健康科普和就医决策支持，不直接用于临床诊断。

## 建议 PPT 结构

1. 问题：健康信息割裂，普通聊天模型不可追溯。
2. 方案：Neo4j 证据 + DeepSeek 生成 + 规则安全层。
3. 演示：连续健康管理、证据问答、急症分诊、3D 图谱。
4. 技术：数据模型、检索链路、严格提示词、降级策略。
5. 创新：图谱驱动记忆、个人趋势、可解释回答。
6. 验证：141K 实体、685K 关系、急症用例、上下文持久化。
7. 价值与边界：健康科普和就医辅助，不替代医生。
